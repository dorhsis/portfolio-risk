# Portfolio Risk

Риск-аналитика портфеля американских акций и ETF: концентрация, вклад каждой позиции в риск,
корреляции, факторы Fama–French и исторические стресс-тесты. Отвечает на вопрос «насколько я
рискую и почему», а не «что купить».

## Быстрый старт

```bash
uv sync
uv run portfolio-risk examples/portfolio.csv
```

Опции:

| Флаг | Что делает |
|---|---|
| `--explain` | объяснение отчёта простым языком от LLM (см. ниже) |
| `--json` | машиночитаемый отчёт (контракт для API и LLM-слоя) |
| `--benchmark QQQ` | другой бенчмарк (по умолчанию `SPY`) |
| `--lookback-years 5` | окно оценки риска (по умолчанию 3 года) |
| `--no-factors` | не загружать факторы Fama–French |

Формат портфеля — CSV с колонками `ticker,shares` (регистр не важен, лишние колонки
игнорируются, дубли тикеров суммируются, только длинные позиции):

```csv
ticker,shares
AAPL,40
BRK.B,15
QQQ,10
```

## Что считается и как

Все метрики считаются для **текущих весов**, как будто портфель держали весь период. Это ответ
на «насколько рискован портфель, который у меня сейчас», а не оценка прошлых сделок.

- **Окно анализа** — последние N лет, но не раньше начала торгов самой молодой бумаги
  (все бумаги выравниваются по общим датам). Меньше 60 общих дней — ошибка.
- **Концентрация** — веса по рыночной стоимости, индекс Херфиндаля `HHI = Σw²`,
  эффективное число позиций `1/HHI`, доля топ-5, разбивка по секторам.
- **Риск** — годовая волатильность `σ_daily·√252`, бета к бенчмарку, максимальная просадка,
  исторические VaR и CVaR 95% на 1 день (в процентах и долларах).
- **Вклад в риск** — доля дисперсии портфеля от каждой позиции:
  `RC_i = w_i·(Σw)_i / (wᵀΣw)`, в сумме 100%.
- **Корреляции** — средняя попарная и пары с корреляцией ≥ 0.80.
- **Факторы** — регрессия избыточной доходности на Fama–French 5 + Momentum
  (рынок, размер, value, прибыльность, инвестиции, моментум), R² показывает,
  насколько портфель объясняется факторами.
- **Стресс-тесты** — текущие веса в окнах «пик → дно» S&P 500: доткомы (2000–2002),
  кризис 2008, COVID (2020), рост ставок (2022). Бумаги, которых тогда не было,
  оцениваются как `бета × доходность бенчмарка` и помечаются в отчёте.

## Объяснение от LLM (`--explain`)

Модель получает JSON-отчёт и пересказывает его в 5–7 предложениях: где сосредоточен риск,
чем портфель отличается от бенчмарка, самый тяжёлый стресс-сценарий в долларах. Цифры она
не считает, только объясняет готовые. Системный промпт запрещает рекомендации «купить/продать»
и прогнозы цен.

Работает с любым OpenAI-совместимым API (`POST {base_url}/chat/completions`). По умолчанию —
Meta Model API:

```bash
cp .env.example .env   # затем впиши ключ в LLM_API_KEY
uv run portfolio-risk examples/portfolio.csv --explain
```

| Переменная | Значение |
|---|---|
| `LLM_API_KEY` | ключ API (только в `.env`, файл в `.gitignore`) |
| `LLM_BASE_URL` | `https://api.meta.ai/v1` |
| `LLM_MODEL` | `muse-spark-1.3` |
| `LLM_MAX_TOKENS` | необязательно, по умолчанию 4000 |

`muse-spark-1.3` — reasoning-модель: часть бюджета `LLM_MAX_TOKENS` уходит на размышления
до ответа. Если бюджета не хватит, CLI так и скажет, и его можно увеличить. Переменные
окружения имеют приоритет над `.env`. Если LLM недоступен, отчёт всё равно печатается,
а код выхода — 1.

## Веб-версия

Та же аналитика в браузере: позиции вставляются в форму или загружаются CSV-файлом, отчёт
рисуется графиками, объяснение от LLM доступно по паролю.

```bash
uv run uvicorn app:app --reload   # http://127.0.0.1:8000
```

| Эндпоинт | Запрос → ответ |
|---|---|
| `POST /api/report` | `{"portfolio": "<CSV>", "benchmark": "SPY", "lookback_years": 3, "factors": true}` → тот же JSON, что `--json` |
| `POST /api/explain` | `{"report": {...}, "password": "..."}` → `{"explanation": "..."}` |

Объяснение тратит квоту владельца LLM-ключа, поэтому оно выключено (503), пока на сервере не
задан `EXPLAIN_PASSWORD`, а неверный пароль даёт 401. Ограничения: до 50 позиций в портфеле,
отчёт для объяснения — до 50 000 символов. Ошибки ввода — 400/422, сбой источника котировок
или LLM — 502, тело ошибки всегда `{"detail": "..."}`.

### Деплой на Vercel

`app.py` в корне — точка входа FastAPI. Vercel ставит пакет из `pyproject.toml` и `uv.lock`,
версию Python берёт из `.python-version`. `.env` на Vercel не загружается (`.vercelignore`),
секреты задаются переменными окружения проекта:

```bash
npx vercel login
npx vercel link
npx vercel env add LLM_API_KEY production   # так же LLM_BASE_URL, LLM_MODEL, EXPLAIN_PASSWORD
npx vercel deploy --prod
```

Yahoo Finance иногда отказывает запросам с IP дата-центров, тогда `/api/report` вернёт 502
с причиной.

## Источники данных и ограничения

- **Цены и секторы** — Yahoo Finance через `yfinance`: бесплатно, подходит для прототипа,
  но условия Yahoo запрещают коммерческое использование. Перед продуктом заменить
  `fetch_prices` / `fetch_sectors` в `market_data.py` на лицензированного провайдера.
- **Факторы** — Kenneth French Data Library, обновляется с лагом ~1–2 месяца, поэтому
  в регрессии меньше дней, чем в окне анализа. Если загрузка не удалась, отчёт строится
  без факторов и объясняет причину.
- Только USD, только длинные позиции, ETF пока не раскладываются на составляющие.

## Структура

```
src/portfolio_risk/
  portfolio.py      загрузка и валидация CSV
  concentration.py  веса, HHI, секторы
  risk.py           доходности, волатильность, бета, просадка, VaR, вклад в риск
  correlation.py    сводка корреляционной матрицы
  factors.py        регрессия Fama–French
  stress.py         исторические сценарии
  report.py         сборка отчёта, текст и JSON
  explain.py        объяснение отчёта через OpenAI-совместимый LLM API
  market_data.py    Yahoo Finance и Ken French
  cli.py            точка входа CLI
  web.py            HTTP API веб-версии (FastAPI)
  static/           страница: HTML, CSS, JS без сборки
app.py              точка входа веб-версии для Vercel и uvicorn
```

Аналитические модули — чистые функции без сети: на входе цены и портфель, на выходе метрики.
